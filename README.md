Программа "Система управления очередью на посадку в самолет"

Описание


Программа предназначена для управления приоритетной очередью пассажиров на посадку в самолет. Реализована на C++ с использованием консольного интерфейса.

Функциональность


Основные возможности:

-Добавление пассажиров в очередь (вручную или из файла)

-Извлечение первого пассажира из очереди

-Удаление всей очереди

-Поиск и отображение пассажиров:

  -По ключевым словам
  
  -По приоритету обслуживания
  
  -Полный список очереди
  
-Сохранение данных в файл

Система приоритетов:

Эконом-класс - базовый приоритет

Обладатели серебряных карт - повышенный приоритет

Льготные пассажиры - средний приоритет

Бизнес-класс - высокий приоритет

Особый приоритет - наивысший приоритет

Требования


-Компилятор: Visual Studio 2019+ с поддержкой C++17

-ОС: Windows 10/11

-Дополнительно: Установленные кодеки кириллицы

Сборка и запуск


Сборка в Visual Studio:

1. Откройте проект в Visual Studio
2. Убедитесь, что все файлы включены в проект:
-Program.cpp в "Исходные файлы"
-interface_lib.h, Priority_queue_lib.h в "Файлы заголовков"
-interface_lib.cpp, Priority_queue_lib.cpp в "Файлы ресурсов"
3. Соберите решение: Сборка → Собрать решение
4. Запустите: Запуск без отладки

Использование


Управление в программе:

-Стрелки Вверх/Вниз - перемещение по меню

-ENTER/Стрелка вправо - подтверждение выбора

-ESC - выход в главное меню

-Стрелка влево - возврат назад

-Backspace - удаление символа при вводе

Форматы данных


ФИО пассажира:
Только кириллические и латинские буквы, допустимы пробелы и дефисы

Пример: Иванов Иван Иванович

Номер места:

Формат: <число><буква>

Пример: 12A, 5F, 25C

Класс обслуживания:

Выбирается из предустановленного списка, определяет приоритет в очереди

Формат файлов данных:

Для загрузки пассажиров используется формат с расширением .txt

Каждый пассажир записывается тремя строками:

ФИО

Номер места

Класс обслуживания

Пример:

Иванов Иван Иванович

12A

Эконом-класс

Петрова Мария Сергеевна

5B

Бизнес-класс

...

Особенности реализации


Валидация данных:

-Проверка корректности ФИО

-Валидация формата номера места

-Проверка уникальности имен и мест

-Защита от специальных символов в именах файлов

Разработчикам


Основные модули:

Priority_queue_lib - реализация приоритетной очереди

interface_lib - пользовательский интерфейс

Program.cpp - главный цикл программы и меню
